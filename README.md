# CS-A-Z

A collection of C# console applications built while learning the basics of the language.

## Projects

### 🔍 AgeDetective
Determines a person's life stage based on their age.

### 💰 SalaryCalculator
Calculates net salary based on given inputs.

### 🏦 BankAccount
Simulates basic bank account operations.

## Tech Stack

- Language: C#
- Framework: .NET Framework
- IDE: Visual Studio
